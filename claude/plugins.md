# Installed plugins

| Plugin | Marketplace | Marketplace source |
| --- | --- | --- | --- |
| `pohuy` | `pohuy` | GitHub `smixs/pohuy` |
| `postman` | `claude-plugins-official` | GitHub `anthropics/claude-plugins-official` |

Install, inside Claude Code:

```
/plugin marketplace add smixs/pohuy
/plugin marketplace add anthropics/claude-plugins-official
/plugin install pohuy@pohuy
/plugin install postman@claude-plugins-official
```
